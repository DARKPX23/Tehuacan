# 🌵 Descubre Tehuacán

Página web escolar sobre Tehuacán, Puebla: el **mole de caderas** y el **Manantial Peñafiel**.

## 📁 Estructura
```
index.html       → Inicio (tarjetas, minijuego, eventos, contacto)
mole.html        → Mole de caderas (historia, preparación, temporada, ¿controversial?)
manantial.html   → Manantial Peñafiel (historia, marca, cómo visitar)
css/estilos.css  → Diseño de todo el sitio
js/datos.js      → Información editable (ingredientes, pasos, datos curiosos, eventos)
js/main.js       → Menú de celular, eventos, encuesta y formulario
js/juego.js      → Minijuego "Prepara el mole de caderas"
img/             → Fotos (opcional)
```

## 🖼️ Fotos (opcional)
Si agregan estas fotos a la carpeta `img/`, la página las usa solita. Si no, se ven degradados:
- `img/valle.jpg` → banner del Inicio
- `img/mole.jpg` → tarjeta y banner del mole
- `img/manantial.jpg` → tarjeta y banner del manantial

## 🚀 Publicar en GitHub Pages
1. Sube todos los archivos a un repositorio (con `index.html` en la raíz).
2. Ve a **Settings → Pages**.
3. En *Source* elige la rama `main` y la carpeta `/ (root)`, y guarda.
4. En un par de minutos queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
